# Genshin Team Finder

A simple tool to help people build Genshin Impact teams. Mark the characters you own, pick one, and see the best teams you can build for them right now.

Team data comes from [KeqingMains (KQM)](https://keqingmains.com/) quick guides, and each team links back to its guide. Covered guides: Neuvillette, Mavuika, Arlecchino, Flins, Skirk, Raiden Shogun, Keqing, Columbina, Varesa, Zibai, Varka, Wriothesley, Nefer, Sandrone and Lohen. Character list is up to version 7.2.

## Features

- Roster picker with constellations, saved in your browser
- Best owned team per KQM archetype, with swap options for each slot
- "One character away" teams that show what you're missing
- Screenshot import: reads character names and constellations from HoYoLAB character-list screenshots right in your browser (Tesseract.js for names, the corner badge for constellations); nothing is uploaded
- On claude.ai only: Claude reads screenshots instead, and can explain each team pick

## Run it

It's a single static file. Open `index.html` in a browser, or serve it with GitHub Pages.
